# Wayfarer — Travel Recommendation Web Application

A simple travel recommendation website built with HTML, CSS, and vanilla JavaScript.

## Pages
- **Home (`index.html`)** — introduction, navigation bar with a search box, and category buttons (Beaches / Temples / Countries) that display recommendation cards with two images each.
- **About Us (`about.html`)** — company story, values, and imagery.
- **Contact Us (`contact.html`)** — a working contact form (name, email, subject, message).

## Features
- Responsive navigation bar with a mobile menu toggle.
- Live search box that filters recommendations by name or description.
- Category buttons that filter recommendations by type (beach, temple, country).
- Each recommendation card shows two images, a name, and a short description.

## Tech
- HTML5, CSS3 (custom properties, responsive grid/flexbox), vanilla JavaScript (no frameworks).
- Google Fonts: Fraunces (display) + Karla (body).

## Deployment
This site is deployed using GitHub Pages.
